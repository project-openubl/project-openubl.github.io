El **resumen diario** es un documento que agrupa las boletas (y las notas de crédito o débito de boletas) emitidas en un día y las informa a la SUNAT en un solo envío. También sirve para modificar o anular boletas ya informadas.

Igual que la [comunicación de baja](./03-void-documents.mdx), el resumen se procesa de forma **asíncrona**: al enviarlo la SUNAT responde con un **ticket**, que luego consultas para obtener el resultado.

## Crear el resumen

Cada línea del resumen describe una boleta: su tipo y número, el cliente, los importes y los impuestos, y un **tipo de operación** del Catálogo 19:

| Código | Operación |
| ------ | --------- |
| `1` | Adicionar |
| `2` | Modificar |
| `3` | Anulado |

El identificador del documento, `RC-AAAAMMDD-N`, se calcula a partir de la fecha de emisión del resumen y del correlativo (`numero`) que indicas.

```java
SummaryDocuments resumen = SummaryDocuments.builder()
        .numero(1L)                                          // RC-AAAAMMDD-1
        .fechaEmisionComprobantes(LocalDate.of(2026, 11, 14)) // fecha de las boletas
        .proveedor(Proveedor.builder()
                .ruc("12345678912")
                .razonSocial("Softgreen S.A.C.")
                .build())
        .comprobantes(List.of(SummaryDocumentsItem.builder()
                .tipoOperacion("1")                          // Catálogo 19: adicionar
                .comprobante(SummaryDocumentsItemComprobante.builder()
                        .tipoComprobante("03")               // boleta (Catálogo 1)
                        .serieNumero("B001-1")
                        .cliente(SummaryDocumentsCliente.builder()
                                .tipoDocumentoIdentidad("1") // DNI
                                .numeroDocumentoIdentidad("12345678")
                                .build())
                        .valorVenta(SummaryDocumentsValorVenta.builder()
                                .importeTotal(new BigDecimal("236.00"))
                                .gravado(new BigDecimal("200.00"))
                                .build())
                        .impuestos(SummaryDocumentsImpuestos.builder()
                                .igv(new BigDecimal("36.00"))
                                .igvTasa(new BigDecimal("18")) // porcentaje: 18 = 18 %
                                .build())
                        .build())
                .build()))
        .build();

String xml = new XBuilder().build(resumen);
```

:::warning Los importes del resumen no se calculan

A diferencia de una factura o boleta, en el resumen **tú indicas** los importes y los impuestos de cada línea; xhandler no los calcula ni los compara con las boletas originales. Usa los totales que obtuviste al crear cada boleta (revisa [Cálculos de impuestos y totales](../05-fundamentals/04-calculations.mdx)).

:::

:::caution La tasa del IGV es un porcentaje

En las líneas del resumen, la tasa del IGV (`igvTasa` / `igv_tasa` / `IgvTasa`) es un **porcentaje**: `18` significa 18 %. En cambio, en los `Defaults` y en la factura la tasa es una **fracción**: `0.18`. Esto aplica a los cuatro lenguajes. Si escribes `0.18` en el resumen, el XML dirá 0.18 %.

:::

Lo único que se completa solo:

- `documentoId` / `documento_id` / `DocumentoId`: `RC-AAAAMMDD-N`.
- Fecha de emisión del resumen: hoy en Perú.
- Moneda: `PEN`.
- IGV de cada línea: `0` si no lo indicas.
- Tasa del IGV de cada línea: la de los `Defaults`, convertida a porcentaje (`0.18` → `18`).

Cada línea admite además otros importes en el valor de venta (`exonerado`, `inafecto`, `gratuito`, `otrosCargos` / `otros_cargos`) y otros impuestos (`icb`, `isc`, `ivap`, `otros`).

### Notas de boletas y anulaciones

- **Nota de crédito o débito de una boleta**: usa tipo de comprobante `07` o `08` e indica la boleta afectada en `comprobanteAfectado` / `comprobante_afectado` / `ComprobanteAfectado` (con `tipoComprobante` `03` y su `serieNumero`).
- **Anular una boleta**: agrega una línea con la boleta y tipo de operación `3`.

## Enviar y consultar el ticket

El resumen se firma y se envía con `FileSender`. xhandler usa el servicio de resúmenes de la SUNAT (`sendSummary`) en las URLs de facturas, y la consulta del ticket va al mismo servicio. El flujo es el mismo de la [comunicación de baja](./03-void-documents.mdx#enviar-y-consultar-el-ticket); aquí `signed` es el XML firmado y `sender` un `FileSender` configurado como en el [Inicio rápido](../03-quickstart.mdx).

<TabItem value="java" label="Java">

```java
SunatResponse sent = sender.sendFile(signed);
if (!sent.isTicket()) {
    throw new IllegalStateException(sent.getStatus() + " " + sent.getMetadata().getDescription());
}
String ticket = sent.getSunat().getTicket();

SunatResponse result = sender.verifyFileTicket(signed, ticket);
while (result.getStatus() == Status.EN_PROCESO) {
    Thread.sleep(5_000);
    result = sender.verifyFileTicket(signed, ticket);
}
System.out.println(result.getStatus() + " " + result.getMetadata().getDescription());
```

<TabItem value="rust" label="Rust">

```rust
let ticket = match sender.send_file(&signed).await?.response {
    SendFileAggregatedResponse::Ticket(ticket) => ticket,
    SendFileAggregatedResponse::Fault(fault) => anyhow::bail!("{} {}", fault.code, fault.message),
    SendFileAggregatedResponse::Cdr(_, cdr) => anyhow::bail!("CDR inesperado: {}", cdr.description),
};

loop {
    match sender.verify_file_ticket(&signed, &ticket).await?.response {
        VerifyTicketAggregatedResponse::NoCdr { status_code }
            if Status::from_code_str(&status_code) == Status::InProgress =>
        {
            tokio::time::sleep(std::time::Duration::from_secs(5)).await;
        }
        VerifyTicketAggregatedResponse::Cdr(_, cdr) => {
            println!("{} {}", cdr.status(), cdr.description);
            break;
        }
        VerifyTicketAggregatedResponse::NoCdr { status_code } => {
            println!("sin CDR, código {status_code}");
            break;
        }
        VerifyTicketAggregatedResponse::Fault(fault) => {
            println!("{} {}", fault.code, fault.message);
            break;
        }
    }
}
```
