En Java hay integraciones para Spring Boot, Quarkus y Jakarta EE (CDI con MicroProfile Config). Configuras la empresa en tus propiedades y luego inyectas un `SunatClient` compartido y un `FileSender` listo para enviar. Quarkus, además, te da un `XBuilder` configurable.

## Qué te da cada integración

| | Spring Boot | Quarkus | Jakarta EE / MicroProfile |
|---|---|---|---|
| Dependencia | `spring-boot-xsender` | `quarkus-xbuilder`, `quarkus-xsender` | `xsender-cdi` |
| Prefijo de propiedades | `xsender.*` | `quarkus.xsender.*`, `quarkus.xbuilder.*` | `xsender.*` |
| `SunatClient` | Sí | Sí | Sí |
| `FileSender` | Solo si defines `xsender.company.username` | Sí, si defines `quarkus.xsender.company.*` | Sí, si defines `xsender.company.*` |
| `XBuilder` | No (créalo con `new XBuilder()`) | Sí | No (créalo con `new XBuilder()`) |

Los beans son singletons: un único `SunatClient` (conexiones y tokens) y un `FileSender` para la empresa configurada, que usa ese mismo `SunatClient`. `XBuilder` y `XSigner` son seguros para usar desde varios hilos, así que puedes tenerlos como campos.

## Configuración

Las claves son las mismas en los tres frameworks; solo cambia el prefijo. Los ejemplos usan el entorno beta.

| Propiedad (`company.*`) | Para qué sirve |
|---|---|
| `invoice-url` | Facturas, boletas, notas, resúmenes y bajas |
| `perception-retention-url` | Percepciones, retenciones y reversiones |
| `despatch-url` | Guías de remisión |
| `username`, `password` | Usuario y clave SOL |
| `client-id`, `client-secret` | Credenciales de la API, solo para guías de remisión |

## Inyectar y usar

<Tabs groupId="java-framework" queryString>
<TabItem value="spring" label="Spring Boot">

```java title="InvoiceController.java"
import io.github.project.openubl.xbuilder.XBuilder;
import io.github.project.openubl.xsender.FileSender;
import io.github.project.openubl.xsender.sunat.SunatClient;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;

@RestController
public class InvoiceController {

    private final FileSender xsender;       // la empresa de xsender.company.*
    private final SunatClient sunatClient;  // compartido
    private final XBuilder xbuilder = new XBuilder();

    public InvoiceController(FileSender xsender, SunatClient sunatClient) {
        this.xsender = xsender;
        this.sunatClient = sunatClient;
    }

    @PostMapping("/api/file/upload")
    public String upload(@RequestParam("file") MultipartFile file) throws IOException {
        // Recibe un XML ya firmado y lo envía
        return xsender.sendFile(file.getBytes()).getStatus().toString();
    }
}
```

```java title="InvoiceResource.java"
import io.github.project.openubl.xbuilder.XBuilder;
import io.github.project.openubl.xbuilder.models.Invoice;
import io.github.project.openubl.xsigner.SigningKey;
import io.github.project.openubl.xsigner.XSigner;
import io.github.project.openubl.xsender.FileSender;
import io.github.project.openubl.xsender.sunat.SunatClient;
import jakarta.enterprise.context.ApplicationScoped;
import jakarta.inject.Inject;
import jakarta.ws.rs.POST;
import jakarta.ws.rs.Path;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Paths;

@Path("/invoices")
@ApplicationScoped
public class InvoiceResource {

    @Inject
    XBuilder xbuilder;       // con las tasas de quarkus.xbuilder.*

    @Inject
    FileSender xsender;      // la empresa de quarkus.xsender.company.*

    @Inject
    SunatClient sunatClient; // compartido

    private final XSigner xsigner = new XSigner();
    private final SigningKey key;

    public InvoiceResource() throws IOException {
        key = SigningKey.fromPkcs12(Files.readAllBytes(Paths.get("certificado.pfx")), "password");
    }

    @POST
    public String send(Invoice invoice) {
        String xml = xbuilder.build(invoice);
        byte[] signed = xsigner.sign(xml.getBytes(StandardCharsets.UTF_8), key);
        return xsender.sendFile(signed).getStatus().toString();
    }
}
```

## Si falta la configuración

- **Spring Boot**: si no defines `xsender.company.username`, el bean `FileSender` simplemente no se crea (el `SunatClient` sí). Si inyectas `FileSender` sin esa propiedad, Spring falla al arrancar porque no encuentra el bean. Si defines `username` pero no `password`, falla con `IllegalStateException`.
- **Quarkus**: si inyectas `FileSender` sin `quarkus.xsender.company.*`, falla con `IllegalStateException` al crear el bean. Si defines `company`, `username` y `password` son obligatorios.
- **Jakarta EE**: si inyectas `FileSender` sin `xsender.company.username` o sin `xsender.company.password`, falla con `IllegalStateException`.

## Reemplazar los beans o usar varias empresas

Los beans se pueden reemplazar por los tuyos:

- **Spring Boot**: declara tu propio `@Bean` de tipo `SunatClient` o `FileSender` y el de xhandler no se crea.
- **Quarkus**: los beans de xhandler son beans por defecto; un bean tuyo del mismo tipo los reemplaza.
- **Jakarta EE**: produce el tuyo como `@Alternative @Priority(1)`.

El bean `FileSender` envía para **una** empresa. Si emites para varias, inyecta el `SunatClient` compartido y crea un `FileSender` por empresa:

```java
FileSender sender = new FileSender(URLs.production(), credencialesDeLaEmpresa, sunatClient);
```
